# Log-Analyzer-Ai

## Problem Statement
Finding the Signal in 10,000 Log Lines at 3 a.m.

## About the Project
Log Analyzer AI helps developers find important errors in large log files. It groups similar errors and highlights critical issues.

## Features
- Detect errors in log files
- Group similar errors
- Highlight critical incidents
- Display error summaries

## Technology Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open index.html in your browser.
